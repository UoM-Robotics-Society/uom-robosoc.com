Design, build, and test a low-cost, four-legged walking robot.

The RoboDog project focuses on building an agile 4 legged robot that weighs under 10kg on a budget. Working together, team members will design lightweight custom joints, rewire brushless motors for extra torque, and write code to get the robot standing, balancing, and trotting.

Check out the following video to get a better idea of what we plan on doing: [RoboDog by Aaed Musa](https://www.youtube.com/watch?v=GFLa1b1juUo)

**What You'll Work On:**

Mechanical Design & 3D Printing: Assemble lightweight legs, tune rope-driven joints, and make the frame durable.

Electronics & Motor Wiring: Wire brushless motors, set up motor drivers, and connect everything to a central microcontroller.

Programming & Controls: Write simple code to read motor sensors, balance the robot, and program basic walking steps.

Testing & Documentation: Run joint tests, troubleshoot hardware issues, and keep track of our build progress.


**Experience Level:** Advanced. Great for anyone interested in 3D printing, motor controls, basic robotics code, and hands-on making.
